# 知識島 學習冒險 🏝️

給國小一～三年級孩子的練習遊戲（國語、數學、注音、生活、社會、自然、閱讀），題目依南一／康軒／翰林單元與均一教育平台的主題編排。

**開始玩：** https://caroelvis.github.io/knowledge-island/

- 3D 島嶼地圖：單指轉動、雙指縮放，點島嶼出發。可隨時「切換 2D/3D」，不支援 WebGL 的裝置會自動用 2D。
- 一～三年級分開選擇。一年級有注音島。
- 每題都有解析。答錯的題目下一回合會再出現，連續答對 2 次就算熟練。難度依表現自動調整。
- 多位學生，每人有自己的年級。可以改名、刪除。
- 家長 PIN 與分析儀表板，可以備份與還原 JSON。
- 學習紀錄預設只存在這台裝置。用 Google 登入後，會同步到**你自己的** Google 雲端硬碟（`知識島學習紀錄.json`）。程式只用 `drive.file` 權限，只看得到它自己建立的那個檔案。設定方法見 [SETUP-GOOGLE.md](SETUP-GOOGLE.md)。

本站是純靜態網頁，沒有伺服器，也不收集任何資料。

第三方元件：three.js、React（MIT 授權），見 [THIRD_PARTY_LICENSES](THIRD_PARTY_LICENSES)。島嶼模型與題目都是原創。
